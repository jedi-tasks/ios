# Tasks — контекст предметной области

Свой трекер задач по системе «Путь джедая». Цель — постепенно заменить Apple Reminders.
v1 — iPhone-приложение (на Mac запускается как iPad-приложение), всё локально, без сервера и синка.

## Термины

- **Список** (`TaskList`): контейнер задач, порядок списков произвольный. У списка свой цвет (как в Напоминаниях) —
  им красится чекбокс задачи; при импорте цвет берётся из списка Reminders.
  - **Inbox**: системный список, точка входа — туда попадает задача, если список не выбран явно. Не удаляется.
- **Раздел** (`ListSection`): необязательная группа внутри списка, порядок произвольный.
- **Задача** (`TaskItem`; `Task` занято Swift Concurrency):
  - **Планируемый срок** (`plannedDay`): день, когда собираюсь делать. По нему строится «Сегодня».
  - **Дедлайн** (`deadlineDay`): день, позже которого нельзя.
  - Обе даты — без времени, ключ `yyyy-MM-dd`.
  - **Планируемое время** (`durationMinutes`): оценка длительности, не время суток.
  - **Описание** (`notes`): полотно текста; ссылки пишутся текстом.
  - **Ручной порядок** (`manualOrder`): хранится всегда и не теряется при смене режима сортировки.
- **Приоритет** (`Priority`): упорядоченный справочник (название, цвет, знаки, порядок), можно добавлять свои уровни.
  Показывается отдельно от цвета списка — знаками перед названием задачи (`!!!`, `!!`, `!`).
  По умолчанию: «1 — ближайшие дни», «5 — неделя–две», «9 — когда-нибудь». Без приоритета = «не разобрано».
- **Тег** (`Tag`): свободный ввод с автодополнением, связь с задачами многие-ко-многим.
- **Блокер** (`Blocker`): либо ссылка на другую задачу, либо текстовая причина; плюс дата начала.
  У задачи может быть несколько блокеров; она **заблокирована**, пока жив хоть один.
  - Блокер-задача снимается автоматически, когда блокирующую задачу выполнили. Текстовый — вручную.
  - Циклы запрещены. Цепочка блокеров заменяет подзадачи.
- **Режим сортировки** (`SortMode`): у каждого списка свой — вручную, приоритет, планируемый срок,
  дедлайн, длительность. «Сегодня» по умолчанию — по приоритету.

## Экраны v1

Сегодня (планируемый срок или дедлайн ≤ сегодня; заблокированные — приглушённо внизу),
В планах (невыполненные со сроком по дням: Просрочено, Сегодня, Завтра…; день — планируемый срок, иначе дедлайн), Inbox,
Списки → список со сворачиваемыми разделами и выполненными, карточка задачи, быстрое добавление, настройки (приоритеты).
iPhone — таббар; iPad и Mac — боковая панель как в Напоминаниях (плитки «Сегодня» и Inbox, ниже мои списки).
У списка цвет и иконка (SF Symbol). Блокер-задача выбирается через списки → разделы → задачи, поиск — по всем.

## Подборки и назначение перетаскиванием

Под списками — подборки: по приоритету (и «Не разобрано»), по длительности (корзины до 15 мин / 30 мин / 1 ч / 2 ч /
больше) и по тегу. Задачу можно бросить на список, приоритет, корзину длительности, тег, «Сегодня» или Inbox —
она примет значение (тег добавляется к имеющимся; длительность — верхняя граница корзины, «больше 2 ч» = 4 ч).
На iPhone то же — в меню по долгому нажатию на задачу.

## Импорт из Reminders

Кнопка в Настройках: все списки, кроме «Привычки» и «Регулярные»; активные задачи и выполненные за 30 дней.
Повторный запуск без дублей — по `externalId` (`calendarItemIdentifier`), в Reminders ничего не пишется.
Список ищется по имени или создаётся («Inbox» → системный Inbox). Из заметки: `Раздел: X` → раздел,
`Заблокировано: <чем> с <даты>` → текстовый блокер, все `~N мин` / `~N ч` → сумма в длительность.
Срок → планируемый срок; приоритет high/medium/low → 1-й/2-й/3-й уровень справочника.

## Не в v1

Подзадачи, повторы, ссылки на задачи в тексте, блочный редактор, поиск и фильтр по тегу,
двусторонний синк с Reminders (план: CalDAV через свой сервер), сервер (Go + gRPC, как Coin), MCP.

## Правила

- Удаление мягкое (`deletedAt`), у каждой строки `id: UUID` и `updatedAt` — под будущий синк с сервером.
- Выполнение сохраняет `completedAt` (для «итога дня»).
